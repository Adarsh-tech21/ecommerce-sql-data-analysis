E-COMMERCE SQL DATA ANALYSIS PROJECT
====================================

PROJECT OVERVIEW
----------------
This project focuses on analyzing an e-commerce dataset using MySQL and SQL
to extract meaningful business insights from customer, product, transaction,
review, and session data.

The objective of this project is to understand sales performance, customer
behavior, product performance, customer engagement, conversion, reviews,
and churn through SQL-based analysis.


PROJECT OBJECTIVES
------------------
- Analyze customer demographics and behavior
- Evaluate sales and transaction performance
- Identify high-performing products and categories
- Analyze customer spending patterns
- Understand customer engagement across channels and devices
- Analyze conversion and bounce rates
- Study product reviews and customer ratings
- Identify high-value churned customers
- Generate meaningful business insights using SQL


DATASET
-------
The dataset contains 236,000+ records across five tables:

1. customers.csv
   Records: 10,000
   Description: Customer information and demographics

2. products.csv
   Records: 1,000
   Description: Product details, pricing, ratings and inventory

3. transactions.csv
   Records: 120,000
   Description: Sales and transaction information

4. reviews.csv
   Records: 25,000
   Description: Customer reviews and ratings

5. sessions.csv
   Records: 80,000
   Description: Website/app session and engagement data

Total Records: 236,000+
